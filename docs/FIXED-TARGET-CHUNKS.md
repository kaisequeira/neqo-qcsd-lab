# Chunks of a declared fixed condition

The target is fifty admitted full graphs, five fixed conditions, and sixty-four
logical slots per class and condition. The distinct target chunk policy reads
the target progress receipt. Historical SCI counts and old Tamaraw captures
grant no slots to this policy. Complete current application delivery retains
its declared status, request graph, completion, caps and source checks.

## Declare and plan

Publish the first target using the reviewed, released consumer checkout. Keep
that original reader checkout immutable. `tools/rapid_fixed_condition_target.py
chunk-inputs` selects one mode and one existing cohort of one to five classes.
The classes must have identical remaining vectors and homogeneous caps. The
public target chunk commands require both each file and its SHA-256:

```text
python3 -B tools/rapid_target_chunks.py policy --spec BASE_SPEC --spec-sha256 BASE_SHA --chunk-inputs INPUTS --chunk-inputs-sha256 INPUTS_SHA --canonical CANONICAL --canonical-sha256 CANONICAL_SHA --output NEW_POLICY
python3 -B tools/rapid_target_chunks.py plan --spec BASE_SPEC --spec-sha256 BASE_SHA --policy NEW_POLICY --policy-sha256 POLICY_SHA --output NEW_PLAN --spec-output NEW_SPEC
python3 -B tools/rapid_target_chunks.py check --spec NEW_SPEC --spec-sha256 NEW_SPEC_SHA
```

Every name and destination is create-only. The base is the current unscheduled
four-visit serial plan with its own complete current canary. Padded modes need
their genuine current named ModuleB qualification; ordinary input has none.
The new policy authenticates the current canonical, client and installed
control code, the full cohort graphs and caps, and the actual canary's complete
resolved condition. A historical control bridge or qualification witness
cannot supply this authority. The fixed Tamaraw condition is the full declared
8192 configuration and requires fresh matching qualification and canary.

The campaign geometry reuses the checked `ChunkLane`: an explicit offset and
one to sixteen local visits, bounded by logical slot sixty-three. Its campaign
name contains the new policy digest. The unchanged shell selector still checks
that geometry; the rolling image check independently dispatches the distinct
target policy and plan. A name alone grants no authority.

## Recovery and evidence

`successor --spec ... --lane ... --generation ... --output ... --spec-output ...`
preserves the condition, cohort, original policy and logical offsets. Actual
launch still requires the genuine failed immediate predecessor and completed
lifecycle cleanup. A successful peer remains independently accepted. This
package provides serial chunks and serial incomplete-result intake through the
dynamic reader. The existing original and SCI-based chunk routes stay exact.

Independent complete audits and serial partial audits append to target progress
using original measurement labels and raw dependencies. Final publication uses
`publish-final` from the target tool and requires all sixteen thousand distinct
fixed-condition slots. It has no mandatory historical SCI anchor.

## Reader and runtime boundaries

The owned target reader is independent of a capture's installed source and
qualification. Retain its original immutable checkout and original deep
program authority when taking new measurements or changing documentation.
Relocating a target reader is not accepted implicitly: its path-bound relevant
code references and full permission modes stay authenticated. A later explicit
producer-reader compatibility proof must compare those relevant code bytes and
modes and execute the original bound program; unrelated documentation changes
do not justify a new study or traffic qualification. This release's first
declaration and consumer use the same owned reader checkout.

HOST fixtures prove parsing, slot geometry, refusal and closing fences. They
grant no installed qualification, actual capture, simultaneous-worker recovery,
or scientific trace credit. A target scheduling capsule remains a separate
prospective consumer; old capsules are not inferred from this planning policy.
