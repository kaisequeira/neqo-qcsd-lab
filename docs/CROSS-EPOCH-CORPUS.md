## Exact sample coverage

Original four-visit blocks map local visits with `(block − 1) × 4 + local_visit`.
The explicit chunk contract maps with `slot_start + local_visit`; its registered
count is bounded to sixteen. Raw experiments must be complete and contain exactly
the expected accepted workload/setting/local-visit tuples. Final membership must
preserve candidate, class index, workload, canonical site aliases and entire
original resource rows, repeated occurrences, DAG edges and headers.

Publication rejects an incomplete membership, missing slot, duplicate slot across
studies/epochs, moved local visit, repeated result/sample, failed or unclosed lane,
changed Source/release inventory, raw-reference substitution and graph replacement.
It reopens the audit's original operation outputs and dependency fences before a
create-only final manifest. Only exact fifty-by-five-by-sixty-four coverage can
publish scientific credit; HOST fixtures are engineering tests and add none.
