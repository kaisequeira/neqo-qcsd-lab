# Original lane intake with separate measurement code and runtime

The closed overlay Source role in [rapid_target_overlay_source.py](../src/qcsd_lab/rapid_target_overlay_source.py)
binds a clean reviewed module release independently from the actual installed
capture runtime. It requires the genuine module publication, its independent
review and complete file/mode inventory. A trusted installed-runtime reader
must first authenticate the canonical image, client, launchers and original
installation records. The overlay is never labelled installed in that image.

Use [rapid_chunk_partial_lane.py](../tools/rapid_chunk_partial_lane.py) `bind-source`
to register the actual installed runtime from its clean release and seven exact
runtime roles. Use [rapid_target_overlay_source.py](../tools/rapid_target_overlay_source.py)
`bind-source` with explicit `--module-root`, hash-bound `--module-publication`,
hash-bound `--runtime-source-binding`, and a fresh external `--output`.
Every input is operator supplied; no private workspace path is embedded.

Then use [rapid_fixed_condition_target.py](../tools/rapid_fixed_condition_target.py)
`audit-complete` with that overlay registration, exact original completed
independent lane closures, and a fresh audit/output namespace. The unchanged
original epoch proof runs in the authenticated module release. Its request
Source root and every original overlay hash must match that release; runtime
Source, immutable image and client must independently match the installed
registration. Original full graphs, statuses, caps, body policy, intent and
raw deep dependencies remain enforced by the original public proof.

Declare the [fixed target](FIXED-CONDITION-TARGET.md) with all five exact
conditions and available immutable class membership. Initial ordinary/FRONT
carry requires complete condition equality; TAM8192 begins with zero accepted
target slots. Old ordinary/TAM/FRONT history is retained separately. A declaration
or audit does not grant credit: progress publication joins original verified
rows to the target condition and full graph before assigning slots 0–63.
The final target remains 50 × 5 × 64 = 16,000 distinct accepted slots.

This overlay route supports complete original lanes. Existing installed-equality
and partial-reader roles retain their existing contracts. Target-aware chunks,
capsules and final corpus consumers require their own explicit typed integration;
this Source package does not claim installed runtime, capture readiness,
simultaneous workers, recovery or a completed final corpus.
