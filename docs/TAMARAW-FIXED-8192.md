# Prospective fixed TAM8192 condition

The closed campaign field is `tamaraw_configuration_policy:
rapid-tamaraw-initial8192-owned-bootstrap-v1`. Its absence keeps historical
TAM behavior. Present null, unknown values and another defense refuse.

The condition uses the existing Native TOML interface. The full resolved
configuration is generated by
[tamaraw_fixed_configuration.py](../src/qcsd_lab/tamaraw_fixed_configuration.py),
frozen as `inputs/tamaraw-initial8192.toml`, and bound by its exact SHA256 in the
experiment. Native receives `--config`; the conflicting profile/defense selectors
are removed. The complete application and chaff manifests, seed, request policy,
response cap and deadline retain their separate exact bindings.

Only initial receive credit changes: 16 to 8192 bytes on **every manually
controlled application and chaff request stream**. The parser excess ceiling
stays 1000. This is a new client-only traffic condition with an initial unshaped
allowance, and does not claim paper equivalence. A successful diagnostic alone
grants no scientific credit or qualification equivalence.

Normal campaign loading, materialization, promotion, schedule replay, deep
verification and serial rolling/canary readiness bind the same closed field.
The full resource graph, exact declared statuses (including authorized completed
terminal leaves), request headers, H3 endpoints, observed response caps, complete
delivery, FIN/owned-credit proof, chaff identity and physical timing predicates
remain required. The terminal-primary rule admits 8192 only with this explicit
condition and equality of every resolved setting. Old marker absence retains
the strict16 rule.

The portable class-mode stage exposes `--tamaraw-configuration-policy` with this
single value. It requires its own current response qualification and complete
current-delivery policy. Historical qualification reuse, qualification consumer
witnesses, other settings and existing parallel capsules cannot authorize it.
Serial plan publication requires a complete current TAM canary under the new
condition. No old failed attempt or accepted trace is promoted or rewritten.

Historical TAM32 remains auditable under its original condition. It contributes
zero slots to a new fixed8192 target. Existing remaining-slot chunk publication
therefore refuses this tag: it requires a distinct condition target/progress map
before subtracting any prior slots. Typed target mapping, recoverable chunks,
parallel capsules and final corpus intake are subsequent prospective seams;
this Source does not claim those paths are ready. Other modes may be carried
only after their complete fixed configuration identity matches the selected
target. The intended final target remains 50 sites, five fixed settings and
64 independent visits per class/setting.
